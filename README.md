# 💬 ChatSphere

A real-time, secure, and elegant chat application built with the **MERN Stack + Socket.io**.

---

## 🚀 Features

- 🔐 **Authentication** – Secure login/signup with JWT
- 🧑‍🤝‍🧑 **1-to-1 Chat** – Real-time messaging with persistent history
- 🟢 **Live Online Status** – See who’s online instantly
- 🖼️ **Dynamic Avatars** – Profile images change based on gender
- 📤 **Media Ready** – Easily extendable for file/image sharing
- 🌐 **Fully Deployed** – Live on [Render](https://chatsphereapp-jp70.onrender.com)

---

## ⚙️ Tech Stack

- **Frontend:** React + TailwindCSS
- **Backend:** Node.js + Express.js
- **Database:** MongoDB (Mongoose)
- **Real-Time:** Socket.io
- **Hosting:** Render

---

## 📱 UX Highlights

- Responsive for all devices  
- Clean UI & smooth transitions  
- Easy contact search & conversations  
- Instant updates across all devices

---

## 🧠 Why It Stands Out

> Built from scratch to mimic real-world messaging apps with an emphasis on **performance**, **scalability**, and **user experience**.
